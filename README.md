# Rapid Mastery Skill

基于认知科学原理的通用快速学习 Skill，用于 Kimi Code CLI。

## 简介

本 Skill 整合了以下学习理论：
- **80/20 法则**：聚焦核心概念，不追求全面
- **费曼技巧**：以教促学，用简单语言解释复杂概念
- **主动回忆**：通过测试而非重读来强化记忆
- **间隔重复**：在遗忘临界点进行复习
- **认知负荷理论**：将复杂主题拆分为信息块
- **脚手架理论**：提供临时支持，逐步撤除
- **双编码理论**：视觉+语言双重编码增强记忆

## 文件说明

- `SKILL.md` - Skill 定义文件（供 Kimi CLI 使用）
- `对话记录.md` - 创建 Skill 并演示使用的完整对话记录

## Skill 工作流程

1. **诊断** - 了解用户当前水平、学习目标、时间预算
2. **绘制认知地图** - 生成 Mermaid 图，展示 3-5 个核心概念
3. **80/20 精讲** - 逐个讲解核心概念（一句话定义 + 类比 + 重要性 + 常见误区）
4. **主动回忆检查** - 每讲一个概念后提问，强制大脑提取信息
5. **微项目/场景应用** - 实战练习，检验理解
6. **收尾与间隔重复** - 生成 Anki 卡片和自测清单

## 使用方式

在 Kimi CLI 中输入以下触发语即可激活 Skill：
- "我想学 XXX"
- "帮我快速掌握 XXX"
- "怎么理解 XXX"
- "给我讲讲 XXX 原理"
- "教我一下 XXX"
