========================================
  稿仓 Gaocang - 使用说明
  新闻学 Web 前端技术课程实践作品
========================================

【这是什么】
稿仓是一个面向新闻学子的轻量作品集生成工具。
零代码、零安装，双击 HTML 文件就能在浏览器里运行。

【文件清单】
  index.html      - 首页（产品介绍与引导）
  edit.html       - 作品录入页（添加、删除作品）
  portfolio.html  - 作品集展示页（切换模板、预览效果）
  style.css       - 样式文件（含三套模板：极简/卡片/时间轴）
  app.js          - 核心逻辑（LocalStorage 存数据 + 模板渲染）
  README.txt      - 本说明文件

【怎么运行】
  方法1：直接双击 index.html，用浏览器打开
  方法2：把文件夹拖到浏览器窗口里
  方法3：用 VS Code 的 Live Server 插件（推荐，可以自动刷新）

【使用流程】
  1. 打开 edit.html → 填写作品信息 → 点击"保存作品"
  2. 打开 portfolio.html → 点击"加载示例数据"看效果
  3. 在 portfolio.html 顶部切换"极简/卡片/时间轴"三种模板
  4. 用"筛选类型"查看某一类作品
  5. 在"关于我"区域写个人简介，点击保存

【数据存在哪】
  所有作品数据存在浏览器 LocalStorage 里，
  关闭网页不会丢失，换浏览器或清缓存会丢失。
  （这是最小可行版本，如需云端同步需要后续加后端）

【AI 功能在哪】
  在 edit.html 页面，填写标题和类型后，
  点击"AI 生成简介"按钮，会模拟生成一段作品简介。
  （演示版本为模拟生成，实际开发中可接入 Kimi/通义千问 API）

【技术栈】
  - HTML5 语义化标签
  - CSS3（Flexbox + Grid + 媒体查询响应式）
  - JavaScript（ES6+，原生 DOM 操作）
  - LocalStorage 本地持久化
  - 零框架、零后端、零数据库

【中期汇报怎么展示】
  1. 打开 portfolio.html，点击"加载示例数据"
  2. 切换三种模板，展示不同视觉效果
  3. 打开 edit.html，现场录入一件新作品
  4. 回到 portfolio.html，看到新作品已出现
  5. 用手机浏览器打开链接，展示移动端适配

【如何修改】
  用任意文本编辑器（记事本、VS Code、Sublime）
  打开 .html / .css / .js 文件即可编辑。
  修改后刷新浏览器就能看到变化。

【注意事项】
  - 封面图需要是网络图片链接（URL），本地图片路径可能无法显示
  - 如果页面显示异常，按 Ctrl+F5 强制刷新
  - 建议在 Chrome / Edge / Safari 等现代浏览器中打开
